# CareCompanion

The CareCompanion caregiver app shell for the StormHacks 2026 project.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000/home](http://localhost:3000/home).

## MVP shell routes

- `/home`
- `/schedule`
- `/activity`
- `/care-team`
- `/profile`

The current implementation is intentionally limited to the reusable caregiver frame, responsive navigation, page headers, and realistic empty states. Feature workflows, backend integrations, authentication, medical advice, and hardware controls are deferred.
